# AM-CORD AI printable HTML pitch deck

Open `index.html` in a modern browser, then select **Print or save as PDF**.

For a faithful result:

1. Select **Save as PDF**.
2. Use landscape orientation if the browser asks.
3. Enable background graphics.
4. Keep the page size at the document's custom 16:9 size when available. If the browser only offers A4 or Letter, select **Fit to page**.

The page uses six fixed 16:9 slides. It preserves the original PDF's visuals as the source layer and overlays the agreed Zenoh and CO-WHCA* terminology updates.
